Com suas cores vermelha e preta, o Flamengo construiu uma trajetória marcada por grandes jogos, títulos e milhões de torcedores.

Classes e IDs

Este parágrafo usa class="texto-destaque".

A mesma classe pode ser reutilizada em vários elementos.

Este parágrafo usa id="mensagem-unica", que identifica um elemento específico.

Resumo: classes são reutilizáveis; um ID deve ser único na página.

Elementos block e inline

Elementos block

Parágrafos e títulos são exemplos de elementos que normalmente começam em uma nova linha.

Este é um elemento div (block).

Elementos inline

O elemento span é inline e permanece na mesma linha do texto, quando há espaço.

Outros exemplos de inline são links e texto em negrito.
